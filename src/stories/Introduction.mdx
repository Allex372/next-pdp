# Storybook — next-pdp

Мінімальна UI library для PDP. Storybook дозволяє розробляти компоненти **окремо від Next.js pages**.

## Запуск

```bash
npm run storybook        # dev UI на http://localhost:6006
npm run build-storybook  # static build → storybook-static/
```

## Що покрито

| Тема | Де подивитись |
|------|----------------|
| **CSF stories** | `UI/Button`, `UI/Input`, `UI/Select`, `UI/Link`, `UI/Form/ContactForm` |
| **Controls / argTypes** | кожен компонент → Controls panel |
| **Actions** | Button `onClick`, Input/Select `onChange` |
| **Play functions** | Button, Input, Select, Link, ContactForm |
| **Complex story** | `ContactForm` — Input + Select + Button + Link |
| **Autodocs** | вкладка Docs + опис component у parameters |
| **a11y addon** | вкладка Accessibility |
| **Viewport / backgrounds** | toolbar у preview |

## Структура

```
src/components/
  ui/          — Storybook UI library (Button, Input, Select, Link, Form)
  demo/        — helpers для PDP demo pages (без stories)
  widgets/     — app widgets (HeavyWidget тощо)

.storybook/main.ts
.storybook/preview.tsx
```

## Deploy (опційно)

```bash
npm run build-storybook
# завантаж storybook-static/ на S3 / GitHub Pages / Chromatic
```
